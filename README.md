Blue Shield is a Python program that helps check login activities and find suspicious attempts. It shows basic information about the computer and network, keeps track of successful and failed logins, and creates security alerts when someone tries to log in with the wrong password too many times. It also has a password-protected menu and can create a report with all the information and results.

The main goal of the program is to make it easier to check login activities and spot possible security problems. but keep in my mind that is mainly a simualtion not a real act.
